# EON Prototype

A static functional prototype for EON's adaptive health decision-support architecture.

## What this prototype demonstrates

- Certificate of Trust before deep data solicitation
- Independence Promise: understanding changes service, not truth
- User-controlled depth of disclosure
- Conversational onboarding
- A visible, correctable Human Model
- Decision-worthiness before personalization
- Adaptive communication/service posture
- Decision trace and agency-preserving resolution
- Browser-local persistence using `localStorage`

## Important limitation

This is an architecture and interaction prototype. It is **not connected to a live AI model, clinical evidence system, EHR, labs, or wearables**, and it must not be used for real medical decisions.

## GitHub Pages

The site is a single static `index.html`, so GitHub Pages can serve it directly from the `main` branch root.

In the repository, open **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

The expected Pages URL will be `https://bayoutd.github.io/eon-prototype/` after GitHub finishes publishing.
